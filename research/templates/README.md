# Research Templates

This directory holds starter templates for new research notes.

## Which Template to Use
- `concept-note-template.md` — durable ideas and boundaries
- `capability-note-template.md` — reusable cross-tool subsystems or facilities
- `product-note-template.md` — product-specific snapshots with freshness metadata

## Conventions
- Use one canonical home per idea.
- Link to neighboring notes instead of re-explaining them in full.
- Keep scope boundaries near the top when confusion is likely.
- Prefer `Relevance to This Repository` over prescriptive “do this” sections.
- Treat product notes as dated field notes, not timeless truth.

## Common Optional Sections
Use these when they reduce ambiguity:
- `Scope`
- `Canonical Boundary`
- `What This Note Is About`
- `What This Note Is Not About`
- `Durable Distinctions`
- `Relationships to Other Notes`

The goal is consistency, not ceremony. Use the smallest structure that keeps the note clear.
